# 🚓 Type Racer

> **Race. Type. Survive.** ⚡
> A fast-paced, web-based 2D car racing game where typing speed and accuracy directly control your vehicle's speed, stability, and survival.

---

## 🌟 Overview

**Type Racer** combines arcade-style racing with real-time typing mechanics. Built with pure **Vanilla JavaScript, HTML5, and CSS3**, players can choose their car, hone their skills in a solo practice arena, or challenge friends in 1v1 multiplayer rooms. Every correct keystroke accelerates your car, while mistakes damage vehicle stability and health!

---

## ✨ Features

- 🏎️ **Car Selection System**: Choose from multiple custom car sprites with dynamic selection transitions.
- 🎯 **Solo Practice Arena**: Train your typing speed and rhythm with sentence streams across 3 distinct game modes:
  - **Practice Mode**: Generous idle grace time, minimal decay, and low mistake damage.
  - **Race Mode**: Balanced difficulty with moderate stability decay.
  - **Survival Mode**: Fast stability decay, punishing mistake damage, and intense speed challenges.
- ⚔️ **1v1 Multiplayer Room System**: Create a room, generate a unique 6-character code, and compete against opponents.
- 🛞 **HP & Stability System**: Real-time health bars and stability meters. Inactive typing leads to speed decay, while typing errors cause stability wobble and health penalties.
- 🎨 **Modern Cyber-Neon UI**: Dark mode glassmorphism UI with smooth CSS animations, dynamic badges, and responsive HUD design.
- ⚡ **Zero External Dependencies**: Lightweight and fast—runs natively in any modern browser without npm packages or framework builds.
